## 🌟 Live Experience & Core Highlights

### 1. 🏎️ Rosso Milano Showcase ("Born in Italy. Crafted to Inspire.")
- **Cinematic Night Landing:** Ultra-high-resolution photorealistic imagery of *Il Corsa* on rain-slicked Milan asphalt with active lighting reflections.
- **Pure Performance Telemetry Bar:** Real-time animated counters displaying **3.1s** 0-100 km/h, **820 HP** twin-turbo V8, **350 KM/H** top speed, and a **1:08.7** Nürburgring benchmark.

### 2. 🎨 Studio di Configurazione (Interactive Car Builder)
- **Live Paint Customizer:** Toggle between *Rosso Corsa*, *Nero Daytona*, *Giallo Modena*, and *Bianco Italia* with live vehicle render updates.
- **Bespoke Wheels & Calipers:** Select forged monoblock rims, carbon aero-discs, and Brembo ceramic brake calipers.
- **Interior & Cockpit:** Switch between Rosso & Nero Alcantara, Cuoio Natural Leather, and Full Carbon Race Tub.
- **Real-Time Dynamic MSRP Calculator:** Updates vehicle price live ($2,850,000 base + chosen options).
- **Client Build Dossier Generator:** Generates a printable bespoke specification certificate with custom chassis allocation ID.

### 3. ⏱️ The Visceral Cockpit & Tachometer Simulator
- **Interactive Radial Tachometer:** 0 to 9,000 RPM needle with glowing redline at 8,500 RPM.
- **Shift Indicator LEDs:** Cascading green $\rightarrow$ yellow $\rightarrow$ flashing redline lights.
- **Drive Mode Selector:** Strada, Sport, Corsa, and ESC Off dynamics.
- **Accelerator Pedal / Spacebar Rev:** Spools twin turbochargers and synthesizes real V12 exhaust roar via the **Web Audio API**.

### 4. 📸 Full-Screen Darkroom Lightbox Gallery
- Interactive panoramic gallery featuring Amalfi coast passes, forged metallurgy, front S-duct aerodynamics, titanium exhaust diffusers, and Lake Como lifestyle photography.
- Click any photograph to launch the full-screen lightbox with keyboard navigation (`Left`, `Right`, `Escape`).

### 5. 🎬 Official Film Premiere & Track Telemetry HUD
- Interactive cinema modal featuring the Autodromo Nazionale Monza hot-lap simulation with live speed and cornering telemetry.

### 6. 📋 Scheda Tecnica (Official Specifications)
- Complete technical homologation data across Powertrain, Dynamics, and Carbon Monocoque Architecture.

### 7. 🚚 Commercial Logistics & Fleet Rental Portal
- Access the integrated Commercial Vehicle Rental platform anytime via `index_logistics_backup.html` or the navigation directory.
- Features multi-page vehicle catalogs, booking engines, driver registrations, and user dashboards.

## 💻 Local Development Setup

To run this repository locally:

```bash
# 1. Clone the repository
git clone https://github.com/Brajesh2244/Commercial-vehicle-Rental-Services-.git

# 2. Navigate to the project directory
cd Commercial-vehicle-Rental-Services-

# 3. Start a local server (Python 3)
python -m http.server 8000

# 4. Open in your browser
http://localhost:8000
```
